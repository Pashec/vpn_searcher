# vpn_searcher (UTM5 Staff Memo)

Легковесный асинхронный веб-сервис на FastAPI для быстрого поиска памяток сотрудников, сетевых реквизитов и параметров VPN в корпоративном биллинге NetUP UTM5.

## Зачем это нужно

Штатный десктопный клиент `utm-admin` тяжелый, медленный и перегружен интерфейсом, если задача системного администратора или специалиста техподдержки — просто найти учетные данные сотрудника, выдать ему реквизиты доступа или распечатать служебную памятку при настройке рабочего места.

Этот сервис решает конкретную прикладную задачу:
1. За пару секунд находит карточку сотрудника по любому из трех критериев: ФИО, IP-адрес или MAC-адрес.
2. Показывает все необходимые данные в одном месте: подразделение, номер комнаты, внутренний телефон, тариф, локальный IP, MAC, учетку от веб-статистики и параметры корпоративного VPN (PPTP).
3. Позволяет в один клик скопировать любой реквизит в буфер обмена.
4. Умеет сразу отправлять готовую памятку на печать (Ctrl + P) — верстка адаптирована для печати официального черно-белого документа на листе А4.

## Возможности

* Поиск без лишних действий: ввод имени, IP или MAC в одной строке с переключением режима.
* Автоматическая нормализация MAC-адресов: любые форматы разделителей (`:` или `-`) и регистр приводятся к корпоративному виду `00-11-22-33-44-55`.
* Режим Mock: встроенный сервис с тестовыми данными для автономной разработки и проверки логики без прямого подключения к боевому серверу биллинга.
* Встроенная консоль логов: скрытое окно системных событий прямо в интерфейсе (вызывается кнопкой в шапке или клавишами Ctrl + ~), отображает статус обращений к ядру UTM5 и сетевые ошибки.
* Портативность: сервис собирается в единый исполняемый `.exe` файл, который можно запускать с флешки на рабочих компьютерах без установки Python.

## Архитектура и стек

* Язык: Python 3.11+
* Веб-фреймворк: FastAPI (полностью асинхронный)
* Валидация и контракты данных: Pydantic v2
* Сервер: Uvicorn
* Фронтенд: Чистый HTML5, CSS3 и Vanilla JS без тяжелых сторонних фреймворков и сборщиков
* Сборщик: PyInstaller

Структура проекта:
```text
utm_admin_analog/
├── app/
│   ├── api/v1/          # Контроллеры FastAPI и валидация параметров
│   ├── core/            # Конфигурация (.env) через pydantic-settings
│   ├── schemas/         # Pydantic-модели данных памятки
│   ├── services/        # Слой логики: базовый интерфейс, Mock-клиент и URFA-клиент
│   └── static/          # Автономный веб-интерфейс (HTML, CSS, JS)
├── dist/                # Папка сборки автономного .exe
├── run.py               # Точка входа для запуска и упаковки
├── requirements.txt     # Зависимости Python
└── .env.example         # Пример конфигурации окружения
```

## Настройка (.env)

Параметры подключения задаются через переменные окружения или локальный файл `.env`:

```env
# Адрес и порт сервера биллинга UTM5
UTM_HOST=10.1.0.29
UTM_PORT=11758

# Служебная учетная запись
UTM_LOGIN=staff
UTM_PASSWORD=your_password_here

# Режим работы:
# True  - тестовые данные (офлайн)
# False - прямое подключение к ядру биллинга
MOCK_MODE=False
```

## Установка и запуск из исходников

1. Клонировать репозиторий:
```bash
git clone git@github.com:Pashec/vpn_searcher.git
cd vpn_searcher
```

2. Создать и активировать виртуальное окружение:
```bash
python -m venv .venv
# Для Windows:
.\.venv\Scripts\Activate.ps1
# Для Linux/macOS:
source .venv/bin/activate
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Скопировать и настроить `.env`:
```bash
cp .env.example .env
```

5. Запустить сервер:
```bash
python run.py
```
Интерфейс автоматически откроется в браузере по адресу `http://127.0.0.1:8000`.

## Сборка в один .exe файл

Сборка портативного файла без консольного окна:
```bash
pyinstaller --noconfirm UTM_Staff_Memo.spec
```
Готовый файл `UTM_Staff_Memo.exe` появится в папке `dist/`. Рядом с ним можно положить настроенный файл `.env`, и приложение автоматически считает параметры при запуске.
